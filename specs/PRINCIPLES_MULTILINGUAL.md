There are 2 senses of multilingual for this project.

1. This project will not use multilingual display. There is no need to build internationalization into
the UI or data structures of this project.  The default settings of this project are US English, except 
that dates should be expressed `YYYY-MM-DD`.

2. Many text elements of wine use the expanded Latin character set. Throughout the project, ensure that 
diacritical marks and alternative punctuation characters can be entered, stored, and displayed faithfully.
